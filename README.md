Módulo de Cadastro de Usuários (HTML + JS)

Este projeto implementa um módulo simples de cadastro de usuários usando apenas HTML, CSS (com Tailwind) e JavaScript puro.

Fluxo de Versionamento

Adota-se o fluxo Git Flow simplificado:

main: Versão estável e pronta para produção.

develop: Versão em desenvolvimento, base para novas features.

feature/*: Branches para novas funcionalidades (ex: feature/validacao-js).

fix/*: Branches para correções de bugs.

refactor/*: Branches para melhorias estruturais de código.
